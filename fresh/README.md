# Модуль «Свежее» — свежие вопросы из мировых новостей

Правило Аркадия (06.11.2026): в каждой игре, где это подходит, первыми идут вопросы по свежим
новостям мира, чтобы игрок всегда чувствовал современную, живую среду. Планка: игроки должны
**восхищаться** нашими вопросами; никто не должен сказать «а вот там вопросы интереснее».

## Темы (одобрены Аркадием 06.11)
`space` космос · `science` наука и медицина · `engineering` инженерия и транспорт ·
`tech` технологии и ИИ · `nature` животные и природа · `records` рекорды и курьёзы ·
`sport` спорт и большие события · `culture` культура и вирусные тренды ·
`local` местные темы (ветка «Найти местные темы, которые цепляют сразу»).

Нельзя: политика, войны, трагедии, катастрофы, смерти, криминал, болезни-страшилки, алкоголь,
азарт, религия; чужие торговые марки в ответах и подсказках (бренды, продукты, лиги, «Олимпиада»).

## Где появляется в играх (studio, `tools/add_fresh.py`)
- **BFEP** и **Bluff Night** — тема «🆕 Свежее» первой в списке; в «Всё вместе» сначала все свежие
  вопросы, потом обычные; после верного ответа — строка-факт 📰. Нужно ≥ 8 активных карточек.
- **Three Clues Daily** — в дни со свежей загадкой (поле `daily`) загадка дня свежая;
  обычный порядок загадок не сдвигается.
- **Say It!** — свежие карточки «Что выберешь?» (поле `wyr`) выпадают раньше остальных.
- Телефон берёт колоду из этого репозитория (`fresh/current.json`, ветка main) и применяет её
  со следующего запуска; без интернета — встроенная копия `games/fresh/deck.js`.

## Формат колоды `decks/fresh-ГГГГ-ММ-ДД.json`
```json
{ "v": 1, "deck": "fresh-2026-11-07", "published": "2026-11-07", "status": "draft",
  "items": [{
    "id": "f261107-01", "cat": "space", "age": 0, "emoji": "🔭",
    "from": "2026-11-07", "expires": "2026-12-07",
    "answer": {"en": "…", "ru": "…", "de": "…", "es": "…", "fr": "…", "zh": "…"},
    "clues":  {"en": ["🔭 …", "… ≥7, от очевидной к редкой"], "ru": ["… столько же, без эмодзи"], "…": []},
    "fact":   {"en": "одна фраза: что случилось", "ru": "…", "…": "…"},
    "wyr":    {"en": ["вариант 1", "вариант 2"], "…": []},
    "sources": [{"title": "…", "outlet": "…", "url": "https://…", "date": "2026-11-05"},
                {"title": "…", "outlet": "другой сайт", "url": "https://…", "date": "2026-11-05"}],
    "checked": "2026-11-07"
  }]}
```
- `age`: 0 — всем (6+), 1 — 12+. Детские игры и режим «Семейный» берут только 0.
- `expires`: срок годности, не больше 60 дней от `from` (обычно 30–45). Просроченные карточки сами исчезают.
- `wyr` — по желанию (для Say It!). `daily` ставит сборщик. `allow` + `note` — исключение из стоп-листа с причиной.
- `status`: `draft` → после OK Аркадия `approved`.

## Порядок работы (кто и как часто)
1. **Каждую среду** (задача «Свежая колода недели») Claude ищет новости за 7–10 дней, отбирает
   10–14 лучших, проверяет каждую по двум независимым источникам, пишет карточки на 6 языках.
2. `python3 fresh/tools/fresh_check.py fresh/decks/<колода>.json --today <дата>` — должна быть ✅.
3. Колода уходит pull request'ом в этот репозиторий; на Пульт — шаг Аркадию «Одобрить свежую колоду».
4. После OK: `status: approved`, `python3 fresh/tools/fresh_build.py`, слить PR в main — телефоны
   подхватят колоду со следующего запуска. Встроенную копию обновляем при каждой новой версии studio.
5. Жалоба игрока ⚑ на свежую карточку — карточку сразу убрать (удалить из колоды, пересобрать), разобрать.

## Проверка фактов
Каждый факт — минимум два источника разных редакций, оба прочитаны; даты совпадают; числа только
если совпадают в обоих. Сомнение — карточку не берём. Подсказки не выдают ответ. Тексты — без HTML и ссылок.
